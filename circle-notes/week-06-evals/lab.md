# Week 6 Agent Evaluation Lab

**Golden Datasets → Task Success → Tool Evaluation → LLM-as-a-Judge → Regression Testing**

A hands-on lab (about 2 hours) where you evaluate a small personal-assistant agent called **Muse**, then catch a sneaky "upgrade" that breaks it before it ships.

The full lab guide and runnable code are in [`agent-eval-lab/`](agent-eval-lab/):

- **Lab guide:** [agent-eval-lab/README.md](agent-eval-lab/README.md)
- **Run everything:** `cd circle-notes/week-06-evals/agent-eval-lab && python3 run_all.py`

No installs are needed (Python 3.9+, standard library only), and it runs offline. Background reading: [Agent Evaluation Fundamentals](fundamentals.md).
