# Agent Engineering Peer Learning Circle — 8-Week Program Guide

An 8-week, hands-on program for learning AI engineering foundations. The program ends with building and validating an AI assistant.

## Who this course is for

This course is for anyone looking to systematically learn AI agent concepts, architecture, and engineering practices.

- **Product managers and technical PMs** who want enough technical depth to scope AI features, define quality bars, and make informed trade-offs.
- **Software, systems, data, and ML practitioners** who want stronger product judgment and hands-on agent-building experience.
- **Career switchers into AI product or agent engineering** who want a concrete portfolio project rather than theory alone.

## What you will learn

1. **Understand AI agents** — prompts, context, retrieval, tools, memory, and state.
2. **Build an AI assistant** — connect knowledge, tools, and workflows into one working system.
3. **Evaluate and improve quality** — use test cases, observable outcomes, and regression checks.

**Build stack:** Python, JavaScript, or TypeScript with an LLM API.

**Time commitment:** about 3–4 hours per week.

## How this program is organized

Each weekly session has three parts:

1. **20 minutes — Learn the essential concept.**
2. **30 minutes — Walk through the lab and Mini Muse demo.**
3. **25 minutes — Open discussion.**

## 8-week roadmap

| Week | Focus | Lab / demo | Deliverable |
| --- | --- | --- | --- |
| 1 | LLM Fundamentals | Make a structured LLM API call | Basic LLM application |
| 2 | Context Engineering | Assemble instructions, history, and state | Context builder and saved state |
| 3 | RAG | Search relevant documents before answering | Retrieval pipeline |
| 4 | Tool Calling + MCP | Let the model request safe external actions | 2–3 validated tools |
| 5 | Agent Engineering | Build a stateful observe → decide → act loop | Workflow agent with stop conditions |
| 6 | Evals | Test outcomes, tool use, and regressions | Golden dataset and automated checks |
| 7 | Production Reliability | Trace calls and handle expected failures | Retries, timeouts, and fallback policy |
| 8 | Mini Muse Demo | Review the complete assistant and system design | Working demo and architecture review |

For each week, use the matching **Knowledge Base** guide, lab, and quiz in the sidebar. The table is the single program overview; the weekly materials contain the details.

## Course project: Mini Muse

Mini Muse is the small personal assistant built across the program. Each week adds one engineering capability:

| Week | Mini Muse capability |
| --- | --- |
| 1 | Understand a request and return structured fields |
| 2 | Retain useful facts and recent conversation context |
| 3 | Search notes and answer from retrieved evidence |
| 4 | Use calendar, contacts, email, weather, and calculator tools |
| 5 | Plan, act, observe, and stop safely |
| 6 | Run a golden dataset against the real assistant |
| 7 | Trace calls, retry failures, and enforce timeouts |
| 8 | Demonstrate the assembled assistant |

Open **Week 8 · Mini Muse Demo** in the sidebar to try the completed assistant.
