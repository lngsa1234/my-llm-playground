# Week 6 · Evals — Lab: Evaluate and Regression-Test an Agent

**Golden Datasets → Task Success → Tool Evaluation → LLM-as-a-Judge → Regression Testing**

A hands-on lab (about 2 hours) where you evaluate a small personal-assistant agent called **Muse**, then catch a sneaky "upgrade" that breaks it before it ships.

The full lab guide and runnable code are in [`labs/week6_agent_eval/`](../../labs/week6_agent_eval/):

- **Lab guide:** [labs/week6_agent_eval/README.md](../../labs/week6_agent_eval/README.md)
- **In the app:** open **Week 6 · Agent Evaluation** in the full site (`streamlit run app.py`), or run just this lab with `streamlit run labs/week6_agent_eval/page.py`. Pick a step in 🧪 Lab parameters, and switch the judge to a real LLM if you like.
- **From the command line:** `python3 labs/week6_agent_eval/run_all.py`

No installs are needed (Python 3.9+, standard library only), and it runs offline. Background reading: [Agent Evaluation Fundamentals](concepts.md) and [Public Benchmarks for Agent Evaluation](concepts-benchmarks.md).
