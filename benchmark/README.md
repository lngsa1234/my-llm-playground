# Week 3 RAG Benchmarks

Question sets for the Week 3 RAG lab, read by the Streamlit app:

- `questions.json` — questions about the fictional NovaTech documents in [`knowledge_base/`](../knowledge_base/), with expected answers and evidence files.
- `hotpotqa_mini_questions.json` — a small HotpotQA subset, built by [`tools/build_hotpotqa_mini.py`](../tools/build_hotpotqa_mini.py).

Public agent-evaluation benchmarks (BFCL, τ²-bench, GAIA and others) are in [`benchmark-datasets/`](../benchmark-datasets/).
