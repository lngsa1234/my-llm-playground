# Week 1 exercises

Standalone scripts from the [Week 1 lab](../../knowledge_base/week-01-llm-fundamentals/lab.md), one per experiment. Run any of them from the repo root, for example:

```bash
python3 exercises/week1/app_2.py
```

`app.old.py` is an earlier single-file version of the Week 1 Streamlit playground (`streamlit run exercises/week1/app.old.py`). The current playground is the Week 1 page of the main app.
